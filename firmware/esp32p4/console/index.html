The console uses Web Serial, which Chrome, Edge and other Chromium browsers have on desktop (Linux, Windows, macOS). Firefox and Safari don't. Open the demo to look around anyway.

Plug the dongle into this computer and press Connect

Pick Stadiacast Dongle (or the name of its current mode: Xbox, PS4, Pro Controller) from the list. The browser remembers it, and reconnects by itself after a mode change or a restart once each mode has been picked once.

It isn't in the list?

Linux: your user needs access to /dev/ttyACM*, usually the dialout group (uucp on Arch): sudo usermod -aG dialout $USER, then log in again. ModemManager may hold the port for a few seconds after plugging in.

Windows: the port shows up as a "USB Serial Device (COMx)" in Device Manager; no driver is needed on Windows 10 or 11.

Firmware: the console needs a build with CONFIG_DONGLE_CONSOLE (on by default since the web console was added).

One wired install first. This dongle's flash layout has no room for a second firmware, so it can't update itself yet. Once, over the programming USB-C port: write stadiacast-dongle-full.bin at address 0x0 with ESP Web Tool (or idf.py flash). Your settings are kept. After that, updates work from here.

Over this USB cable, about 30 s. The old firmware stays until the new one is fully written and checked, and comes back by itself if the new one doesn't start up.
